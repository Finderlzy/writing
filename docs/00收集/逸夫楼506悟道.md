还是从矩阵开始。矩阵，可以理解为**线性变换**，有两种看法。第一种看法是：矩阵表示对基向量的变换；第二种看法是：矩阵表示新的基向量，但是要注意：此时向量的坐标没有变换。两种看法都一样。[[00收集/Jordan 标准型——线性变换的本质#^ee53da|我更倾向于第二个看法]]，因为第一个看法，默认了基向量是（1，0）和（0，1），也就是默认规定了坐标系。

在线性变换的时候，有一些向量在变换之后，**方向是不会发生变化的**，这种向量就是**特征向量**。虽然方向不变，但是可能会被拉伸、收缩，我们把这个伸缩比例称之为”**特征值**“。因为[[02思考/如何简化一个矩阵——特征值与特征向量#^92d134|特征向量可以用来简化矩阵]]，所以我们想要计算它。

由特征向量的定义，我们可以得到一个公式 Ax=λx ，几何意义就是，向量 x 经过矩阵 A 所代表的线性变换后，方向不变，只是伸缩了 λ 倍。然后我们通过简单的代数变化，就可以得到下面这个式子（有的时候，从代数层面很好理解，就不要去想几何意义了，因为想不出来）：
（A - λI）x = 0 。因此，经过简单的代数运算，我们就知道，**特征向量就是新矩阵（A - λI）的零空间的基向量**。

什么是”零空间“？在线性变换的时候，有一些维度会消失。比如在三维空间，如果一个矩阵把新的向量压缩到一个平面，那就有一个维度消失了，此时零空间是这条直线；还是三维空间，如果一个矩阵把新的向量压缩到一条直线，那就有两个维度消失了，此时零空间是一个平面。零空间也是一个空间，换句话说：零空间也有基向量。一个矩阵的特征向量，就是经过代数变化后的新矩阵的零空间基向量......额，其实不是基向量也可以......其实也可以说基向量，因为只要两个向量线性无关，就可以当成基向量。

ok，回到（A - λI）x = 0 这个式子，接下来我们就是要解这个方程。因为我们不考虑向量 x 是零向量的情况，因此这个式子要成立，就只能是（A - λI）= 0 ，也就是矩阵（A - λI）的行列式为 0 。

从而解出特征值 λ 。这里有一个结论：不同的 λ 对应不同的线性无关特征向量。因此如果算出来的 λ 都不一样，这是非常好的情况，然后就挨个把 λ 代入，计算 B x = 0 这个方程组，得到这个矩阵的零空间基向量（感觉叫基础解系会不会好一点？或者基向量的线性组合？），然后每代入一个 λ 都会得到一个特征向量，最后就可以得到”初始矩阵“的所有特征向量了。

但是如果计算出来的 λ 有一两个是相等的，也就是所谓的”有重根“，这个时候我们就要讨论了。把重根 λ 代入（A - λI），得到 B x = 0 ，接着按照正常的高斯消元去解。重点关注消元结束之后，矩阵的秩的情况。换句话说，就是看消元结束后，**自由变量的个数**，因为自由变量对应着零空间的基向量（我说不出来为什么会这样，但是我觉得就是这样）。

假设”初始矩阵“是 3 阶的，然后 λ_1 , **λ_2 =  λ_3** ，我们把  λ_2 代入”初始矩阵“，然后消元新矩阵。如果自由变量个数是一个，也就是这个新矩阵的零空间基向量只有一个，由上面的”**特征向量就是新矩阵（A - λI）的零空间的基向量**。“我们就可以得到：”初始矩阵“的特征向量就是 1 + 1 也就是 2 个；但是，如果自由变量的个数是两个，也就是新矩阵的零空间基向量有两个，我们就可以得到：”初始矩阵“的特征向量就是 1 + 2 = 3 个。

为什么会出现两种不同的情况呢？我的理解是：λ 只是反映了特征向量的伸缩比例，**并没有指示特征向量的方向**。我可以有两个共线的向量，伸缩比例都是 λ ，但是从维度来看，它们只是一维，并不是二维，也就是 λ 没有提供两个方向。

ok，现在我们算出了”初始矩阵“的所有特征向量了，如果特征向量的个数不等于”初始矩阵“的阶数，就不能简化，只能”**近似简化**“，也就是后面要讲的 Jordan 标准型。现在我们先来看特征向量的个数等于”初始矩阵“的阶数这个情况，此时就可以简化，也就是**对角化**，也就是用一个“**对角矩阵**”去表示“初始矩阵”。

具体做法是构造一个“**特征矩阵**”，顾名思义，就是特征向量构成的矩阵。前文说过：“矩阵，可以理解为**线性变换**，有两种看法。第一种看法是：矩阵表示对基向量的变换；第二种看法是：矩阵表示新的基向量，都一样。”在“初始矩阵”的左边，我们先乘上一个“特征矩阵”，使用第二种看法去看待，基向量就会变成特征向量。然后我们知道，“初始矩阵”所对应的线性变换，在“特征矩阵”这里，就是普普通通的伸缩，因此就是左乘一个**对角向量**。然后我们再左乘一个“逆特征矩阵”，就可以回到“初始矩阵”了。
$$
A = \underbrace{P}_{\text{逆向回去}} \;\underbrace{\Lambda}_{\text{伸缩}}\; \underbrace{P^{-1}}_{\text{特征矩阵}}
$$
