想要与数据库建立连接，大致需要这几个过程：连接、发送 sql 语句、翻译、取回结果、翻译

## 连接
---
Spring 框架可以帮我们[[02思考/Spring 框架|提前建立好连接池]]，用的时候直接拿就可以了。

在 `application.properties` 里面配置好数据库的一些信息：
```properties
spring.datasource.url=jdbc:mysql://127.0.0.1:3306/(数据库名字)
spring.datasource.username=(用户名)
spring.datasource.password=(登录密码)
```

以及在 `pom.xml` 里面写上依赖：
```xml
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-jdbc</artifactId>
</dependency>

<dependency>
	<groupId>com.mysql</groupId>
	<artifactId>mysql-connector-j</artifactId>
	<scope>runtime</scope>
</dependency>

```


## 发送 sql 语句、取回结果
---
在这一步 Spring 虽然不能帮我们操作，但是给我们提供了一个工具类—— `JdbcTemplate` 。

我们只需要关注业务逻辑：sql 写什么、返回值怎么存储即可
```java
String sql = "SELECT path, prompt_text, prompt_lang FROM ref_audio WHERE emotion = ?"; // 变量：SQL 语句

jdbc.query(sql,
	(rs, rowNum) -> new RefAudio( // 每查到一行，就变成一个 RefAudio
			rs.getString("path"),
			rs.getString("prompt_text"),
			rs.getString("prompt_lang")),
	emotion);
```

翻译都交给驱动去完成
