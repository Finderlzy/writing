高等代数要解决的问题是什么？Gilbert Strang 老爷子说：”线性代数是用来计算**线性方程组**的。“

方程组我们都知道是什么，所以这句话中，我们唯一要弄清楚的是，什么是“线性”？

说白了，就是每个未知数只能是**一次方**，未知数之间也**不能互相乘**，像 $x^2$、$xy$ 这种都不算。画出来的话，线性方程就是一条**直线**——直的，不会拐弯。3B1B 讲的线性变换也是这个意思：原点不动，网格线变完之后还是直的、平行的、等距的。

一个线性方程组，可以看成是由所有未知数的系数组成的一个**系数矩阵**乘上未知数构成的**未知向量**，得到**最终向量**，也就是 $A\vec{x} = \vec{b}$。

矩阵可以理解为**线性变换**。所以，只要这个线性变换可逆，我们只需要计算当前矩阵的逆矩阵。让最终向量，经过逆矩阵的变换，就可以得到未知向量。

1. 判断这个矩阵所代表的线性变换是否可逆。 <—— 行列式、秩
2. 计算逆矩阵

学了下午的课程，发现上面的思路虽然很顺利，但是“1. 判断这个矩阵所代表的线性变换是否可逆。 <—— 行列式、秩”，这一步的判断其实也依赖消元。

所以更一般的是进行**消元**，只不过是用矩阵形式的消元，由消元得到的**最后一行**来确定这个方程组有几个解。可以类比一元一次方程 $ax = b$ 来判断方程组有几个解：

- $a ≠ 0$，有唯一解（**b 是多少都无所谓**），正常回代就可以了。**几何解释：该矩阵所代表的线性变换没有压缩空间。**
    - 比如 $x+y=3,\ x-y=1$，解出 $x=2,\ y=1$。两条直线**交于一点**。
- $a = b = 0$，有无穷多解。
    - 比如 $x+y=2,\ 2x+2y=4$，第二行减去 2 倍的第一行，得到 $0=0$。第二个方程其实就是第一个乘了 2，是个“复制品”，有用的方程少了一个，未知数就定不下来。两条直线**重合**，线上每个点都是解。
- $a = 0;b ≠ 0$，无解。几何解释：该矩阵所代表的线性变换压缩了空间，但是最终向量**不是零向量**，而是指向列空间之外的向量。列空间是经过变换之后**所有向量构成的集合**，最终向量落在列空间的外面，那自然是无解的。
    - 比如 $x+y=2,\ 2x+2y=5$，消元得到 $0=1$，自相矛盾。两条直线**平行**，永远碰不到。

这也解释了为什么只有这三种情况：直线不会拐弯，所以两条直线不可能恰好碰两次。如果方程里有 $x^2$，画出来是曲线，那就可能恰好有两个解了。

注意，这里的 b 是**消元之后最后一行**右边的那个数，不是一开始的整个 $\vec{b}$。我第一版写成“最终向量是零向量，才有无穷多解”，这是错的——上面那个例子里 $\vec{b} = (2, 4)$，照样有无穷多解。

另外，只看最后一行，前提是方程个数和未知数个数一样多。不一样多的话，要看所有消成全零的行。

下面介绍行列式。行列式的几何意义是：这个行列式对应的矩阵所代表的线性变换**改变面积的比例**。如果行列式为 0 ，也就是前文说过的“这个线性变换压缩了空间”。

计算行列式的方法： 
- 二阶行列式：主对角线之积 - 副对角线之积 
- 三阶行列式：展开第一行，然后按二阶行列式计算 

行列式的一些性质： 
- 交换行和列需要加负号
- 线性组合不会影响行列式的最终结果 
- 可以提取公因式

还没搞懂的：
- **秩**。目前的理解：秩 = 消元后还剩几行不是全 0 = 真正有用的方程有几个。有用的方程个数等于未知数个数，就是唯一解；少于未知数个数，就是无穷多解。正式写法 $r(A) = r(A|\vec{b}) = n$ 还没弄明白，只知道**增广矩阵** $[A \mid \vec{b}]$ 就是把 $\vec{b}$ 拼到 $A$ 的右边。
- 无穷多解的时候，所有的解长什么样？听说是“一个特解 + 零空间”，等学到齐次方程组再说。
- 为什么行列式为 0 就不可逆？现在的理解：行列式为 0 = 空间被压扁了，压扁了就倒不回去了。
