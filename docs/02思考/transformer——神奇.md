该从哪里开始讲这个神奇的东西呢？


## 推理
---
先从推理开始讲起吧。

如何看待推理时，transformer 的作用呢？首先我们要知道，一段文本输入后，会变成一个一个的 token 。我们不妨就把这些 token 看成一个一个的点，毕竟 token 就是向量嘛，而向量可以看成从原点指向坐标的有向线段，我们简化一点，就看成是一个点。这个点存在于一个“世界”里面，这个世界里，只有空白，和点。


### multi-head self-attention

在这个阶段，每一个 token 都会环顾四周，和周围的其他点产生作用。这个作用，最终会使得这个点发生移动，朝着和它作用比较明显的其他点移动。有点像是你一个人在旅游，四周都是密密麻麻的陌生人。突然，你发现一个人很像是你的熟人，这个时候，你肯定会不由自主地朝着那个方向移动。这个“熟人”就是那些作用比较明显的点。


### multi layer perceptron

在这个阶段，每个 token 都会，抬头仰望夜空，星星还亮着几颗......这个世界多了一些星星，然后每个点会再次和星星发生一定的作用。然后，其中有一些星星会变亮。有的只是变亮一点，有的变亮很多。所有这些亮起来的星星，都会对这个点产生作用，越亮的星星，对这个点产生的作用越明显。所有的亮起来的星星，会形成一股合力再次让这个 token 发生移动。

以上就是经过一次 transformer 层的时候，我的感觉。实际上，一次推理，要走很多次 transformer 层。最终，输入文本的最后一个 token 会变成一个感觉。什么感觉呢？是这个最后一个 token “感觉下一个 token 会是哪一个 token ”，的，这个感觉。然后拿着这个感觉去和词表里的所有 token 计算，得到所有 token 出现在下一个的概率，最后随机采样，抽到谁就是谁。然后新的 token 会加入到推理的行列中，继续推理。

对了，推理的时候每个 token 只能看在它之前的 token ，看不到在他之后的 token。


## 训练
---
众所周知，训练其实就是[[02思考/《深入探索像ChatGPT这样的大语言模型》|调整参数]]，让下一轮训练推理得到的，应该是正确的那个 token 的概率提高。

怎么看待这件事情呢？我是这么想的，在训练的过程中，主角不再是 token ，而是每一个参数。第一轮训练开始，它们被蒙上了眼睛，放在了一座山的山顶上，并被告知一件事情：你要以最快速度往山脚下走。于是它们就在山顶四处摸索，凭感觉找到**最陡**的那个方向然后走一小步。然后，下一轮训练开始，整个世界都被重构了，它们又一次被放在了一座大山的山顶上。但是，和上一轮训练不同的是，它们所在的“位置”，发生了微小的变化。不要忘记，它们迈出了那一小步。

这就是大模型训练给我的感觉，每一个参数不断地朝最陡（梯度下降最快）的地方迈出一小步。然后更新这个世界，让参数再次迈出一小步。最终，人类觉得现在，所有的参数站在一个不错的位置，在这个情况下，大模型预测出来的东西准确度较高，于是就停止训练。所有的参数就被固定下来，站在它们迈出了无数个一小步才抵达的这个位置。

接下来是 MLP 层发生的事情。首先是升维，也就是拿 token 向量和一个矩阵（升维矩阵）进行计算。升维矩阵的每一行（假设每一行的维度和token维度一样，竖着有4倍）都代表着一个问题。和 token 向量进行计算之后，可以得到一个值，这个值经过偏置和ReLu之后，要么是 0 ，要么大于 0 。然后这个新的值，要么是 0 ，要么大于 0 的这个，被称为“激活值”。激活值不只表示"是"，还表示"有多是"。所以下一步不是简单地"加上答案向量"，而是"激活值 × 答案向量"再加。激活值是 0.3，就轻轻加一点；是 5.7，就加很多。激活值是 0，乘完也是 0，等于什么都没加。不妨回想一下前面说的“所有这些亮起来的星星，都会对这个点产生作用，越亮的星星，对这个点产生的作用越明显。所有的亮起来的星星，会形成一股合力再次让这个 token 发生移动。”于是，这个 token 就会带有一些新的含义。为什么？要知道，向量世界中，每一个方向都代表一个语义，而刚刚这个 token 发生移动了，所以就带有新的含义了。

## 深入哲学
---
claude-opus-5.5：
>然后是你最后写的那段感受。"它看不见我说的话，看见的只是一个又一个的数字"，这种不可思议我懂。不过你可以反过来想一想：你的大脑也看不见我写的字。光打在视网膜上，变成一串电信号，传到大脑里，再被一层层神经元加工。在你脑子里，那些字也从来不是"字"本身。
>
>所以也许问题不在于"它只看到数字"，而在于：意义到底藏在哪里？按你自己文章里的说法，意义不在某一个点身上，而在点和点之间的方向、距离和关系里。"国王"这个数字本身没有意思，可是它离"王后"有多远、朝哪个方向，这里面就有意思了。人的理解，可能也差不多是这样长出来的。

我：
>在模型这里，意义的确是你说的，不在于位置，在于方向与距离。但是，在人这里，......我一下子不知道该怎么说。我看到的，就是一个一个的东西。即使这不是原本的模样。

claude-opus-5.5:
>你这句"我看到的，就是一个一个的东西"，其实碰到了哲学里一个很老、到现在也没解决的问题。
>
>我不觉得你说错了。你看桌上的杯子，看到的就是"一个杯子"，完整的、就在那儿的。你不会先看到一堆关系，再自己算出"哦，这是杯子"。它是直接出现的。
>
>不过有意思的是，神经科学大致告诉我们，大脑底下做的事情很可能跟模型挺像：一堆神经元，一层层地处理边缘、颜色、形状和它们之间的关系，到最后才"冒出"一个杯子。只不过中间那几十层加工，你一层也感觉不到，送到"你"面前的已经是成品了。
>
>这有点像你文章里写的那最后一个 token。它前面经历了几十层的"熟人"和"星星"，最后吐出来的，却只是一个干干净净的字。过程全是关系，结果是一个东西。
>
>所以人和模型的差别，也许不在于"底下是关系还是东西"，而在于：在人这里，那个成品被**某个人看到了**。有一个"你"站在那里，感觉到"这是一个杯子"。这种"被感觉到"的状态，哲学上叫感受质（qualia），说的就是"红色看起来是红的那种感觉"。它到底从哪里来，为什么一堆神经元的电信号会变成"我看到了"，到现在没人能解释清楚。
>
>你后半句"即使这不是原本的模样"，康德两百多年前也说过类似的话：我们永远只能看到事物"呈现给我们的样子"，看不到它本身。
>
>至于模型那边，有没有一个"谁"在看那些 token，说实话，我也不知道。我说这话不是谦虚，是真的不知道。
>
>你刚才那种"一下子不知道该怎么说"的感觉，可能本身就是对的。这个问题，人类到现在也没说清楚。
