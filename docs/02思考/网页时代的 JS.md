## 为什么学 JS
---
我为什么要学 JS ？为了看懂 TS 的代码。

JS 是浏览器语言，在 nodejs 的帮助下，可以脱离浏览器，运行在本地电脑上。

## JS 基础与类型
---
JS 的基础语法和大部分语言差不多，定义变量、定义函数、调用函数、判断循环等等。

JS 一个很重要的，也是 TS 超出来的部分就是——**JS 的变量没有类型，值有**。一个变量既可以是数，也可以是字符串，还可以是函数。JS 中，函数也可以被变量存储。比如一个函数 `function hello(){...}` ，JS 中是可以像 `let h = hello;` 这么写。需要注意的是，要把函数存进变量的时候不要加括号，**加括号等于立即执行函数**。

## DOM
---
另一个我觉得很重要的，我觉得可以说是**最重要的**东西是 **DOM** ，虽然它不是 JS 的东西。DOM 就是在说：一个 html 文件，根据嵌套关系，不断产生分支；每一个标签，就是一个节点，也可以叫做元素。DOM 的作用：**把一个 html 文件抽象为一棵树，并提供接口给我们去操作树上的每一个元素**。DOM 把每一个页面都抽象为了一个 `document` **对象**，里面有一些方法我们可以使用。

### 获取元素

想要对页面操作，就必须先拿到想要操作的那个元素对象。`getElementByXxx` 就是 DOM 提供的获取元素的方法。常用的是 `getElementById` 、`getElementsByTagName` 、`getElementsByClassName` 。方法的参数看函数名就能知道了，那返回值是什么？是元素。`getElementById` 返回一个元素；另外两个返回一组元素（`HTMLCollection`，类数组，不是真数组）。那什么是元素？一**组** html 标签以及这组标签包裹住的部分，就是一个元素，也就是 html 树中的一个节点。由于 JS 的变量没有类型的特性，拿到一个元素的对象之后，随便拿一个变量就可以接住了。

### 元素的属性

每一个元素也是一个对象，里面有一些属性我们可以直接操作。如：`id` 、`className` 、`innerHTML` 、`innerText` 。前面两个就是在标签里面直接添加或者修改，比如说：

```html
// 有一个盒子
<div id = '111'>box</div>
```

```js
let box = document.getElementById('111');
box.id = 222;
box.className = 'test';
```

```html
<div id="222" class="test">box</div>

// 语法可能不太对，思路是这样。
```

然后我隐约记得，`classList.add()` 用来添加 class，添加其他属性用 `setAttribute()`。

后面两个则是修改标签包裹住的那一段文字，区别在于：`innerText` 是你写什么它就放什么文本在标签的文本处；`innerHTML` 则是，如果你写的话是在描述一个 html 元素，可以识别出来，然后呈现为元素。

## 事件处理
---
下一个是**事件处理**，也是很重要的。由于对比了 HTML事件 、DOM0级事件和DOM2级事件的优缺点之后，我打算主要使用DOM2级事件——给一个**元素的对象**添加一个事件监听的方法 `addEventListener()` 。方法的第一个参数参数是要监听的事件，第二个参数是事件发生之后执行什么函数。这个函数可以使用匿名函数的方法实现。

事件发生之后，会产生一个**事件的对象**，返回给监听函数，默认是不写出来的。通过事件对象我们可以读取到这个事件的一些属性，以及使用 DOM 提供的一些方法。

`event.target` 返回的是一个元素对象，也就是这个事件发生在**哪一个元素**；`event.type` 返回的是一个字符串，表示事件的类型。

DOM 提供的方法中，有两个比较常用。

`event.preventDefault()`，阻止默认事件。举个例子，比如正常来说，我们点击一个网址元素，它是跳转到那个网址的。但是我们可以监听这个网址的点击事件，然后操作这个点击事件，添加这个方法。然后我们再次点击这个网址，就不会跳转了。

另一个是 `event.stopPropagation()` ，这个方法是阻止事件的冒泡。比如说有两个 `div`，大的包住小的。假设我们点击小的 `div`，会发现，大的同样被点击了。但是如果我们监听小的 `div` 的点击事件，并添加这个方法。然后再点击小的，会发现这一次大的没有被点击了。

## 性能优化
---
节流是一个常见的性能优化操作。具体思路就是设置一个单位时间，在单位时间内，一个事件只能执行一次函数。
